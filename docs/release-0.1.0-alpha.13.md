# MineLatino AFK Farm 0.1.0-alpha.13

- Nuevo menú principal con los modos **AFK Directo**, **AFK Reconexión** y **AFK Autónomo**.
- Configuración independiente de mobs, comandos y recorrido para cada modo.
- Recuperación autónoma tras desconexiones, reinicios de host y traslados inesperados.
- Espera de cinco minutos antes de recuperar una sesión en el modo Autónomo.
- Verificación de regreso a la zona de farmeo antes de volver a atacar.
- El saldo de horas AFK continúa siendo único, obligatorio y consumido durante toda la automatización.
- Migración automática de las configuraciones existentes al nuevo formato.
