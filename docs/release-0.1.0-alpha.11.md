# MineLatino AFK Farm 0.1.0-alpha.11

- Mantiene 35 FPS durante una sesión AFK, incluso al cambiar de aplicación con Alt+Tab.
- Evita la pausa al perder el foco y restaura la configuración anterior al detenerse.
- Renueva anticipadamente el permiso AFK y reintenta una vez ante una sesión caducada.
- Cierra el contador del servidor al completar el recorrido o bloquear el ataque.
- Usa un permiso AFK dedicado y persistente, separado del asistente IA.
